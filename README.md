# AI Evaluation Lab

LLM, RAG 및 AI Agent의 품질을 정량적으로 평가하고
회귀를 탐지하기 위한 AI Evaluation 프로젝트입니다.

현재 단계에서는 deterministic evaluation을 시작으로
평가 데이터셋 설계와 자동화된 평가 구조를 구현합니다.
