# AI Evaluation Lab

LLM, RAG, AI Agent의 품질을 수치로 평가하고 성능 저하를 탐지하는 AI Evaluation 프로젝트입니다.

현재는 결정론적 평가로 시작해 평가 데이터셋을 설계하고 자동화된 평가 구조를 구현합니다.
